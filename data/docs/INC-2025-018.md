# INC-2025-018 - mobile-banking-app (SEV3)

## Summary
Date: 2025-05-29. Service: mobile-banking-app. Severity: SEV3. Duration: 25 minutes. Root cause: CDN cache misconfiguration.

## What happened
A stale CDN rule served an outdated login bundle to some Android users, causing blank screens. Customer-facing payment failures were observed during the window.

## Resolution
Cache was purged and the rule corrected.

## Follow-up actions
Add synthetic login check per release.

## Lessons learned
Detection came from customer-impact alerts rather than leading indicators; see the incident severity policy POL-002.
