# INC-2025-041 - payments-api (SEV1)

## Summary
Date: 2025-11-04. Service: payments-api. Severity: SEV1. Duration: 110 minutes. Root cause: database connection pool exhaustion.

## What happened
Month-end salary-day load exhausted the payments-api connection pool again; the pool limit increase from INC-2025-003 had not been applied to this service. Customer-facing payment failures were observed during the window.

## Resolution
Pool limits were raised and autoscaling thresholds adjusted.

## Follow-up actions
Standardise pool configuration across all payment services via shared Helm values.

## Lessons learned
Detection came from customer-impact alerts rather than leading indicators; see the incident severity policy POL-002.
