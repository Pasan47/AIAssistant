# INC-2025-033 - payment-gateway (SEV2)

## Summary
Date: 2025-09-15. Service: payment-gateway. Severity: SEV2. Duration: 38 minutes. Root cause: faulty deployment (config regression).

## What happened
Release 4.12 shipped a wrong retry-count config, causing duplicate payment submissions that were rejected by idempotency checks. Customer-facing payment failures were observed during the window.

## Resolution
Release was rolled back through the pipeline.

## Follow-up actions
Add config diff validation to the release gate.

## Lessons learned
Detection came from customer-impact alerts rather than leading indicators; see the incident severity policy POL-002.
